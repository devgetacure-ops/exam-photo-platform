# Reference portrait

`reference-portrait.jpg` is the ideal exam photograph. Every accepted/rejected
example on the exam pages is derived from it by
`scripts/generate_guidance_examples.py`, so framing is the only thing that
differs between them — a gallery of different people would let a reader
attribute the difference to the person instead of to the mistake.

## What it is

A **synthetic face**: generated by a GAN, not a photograph of any living
person. That is deliberate and not merely a convenient substitute. Using a real
identifiable person's face to advertise a commercial service raises a
publicity-rights question that a permissive copyright licence does not answer;
a synthetic face has no such question because there is no person. It also means
no consent is being stretched and no one can object to how they are portrayed.

Source: `this-person-does-not-exist.com`, which serves StyleGAN output. The
downloaded frame carried a site watermark across rows 16–42 and was a tight
face crop with no headroom, so it was recomposed: watermark band removed, head
centred, canvas extended with the sampled background grey to give margin above
the hair, and framed 3:4 with the shoulders meeting the bottom edge.

## Why it looks like this

It is the photograph a candidate should be trying to match:

- facing the camera square on, looking into the lens
- neutral expression, eyes open, nothing covering the face
- even light, no shadow across the face
- plain light background
- head and shoulders, 3:4 portrait

The portraits under `tests/fixtures/` are the **opposite** of this and must
never be used here. Every one was chosen as an engine edge case — a side
profile, a turban, spectacles, low contrast, a seated full-body shot — so using
one as the ideal teaches candidates the reverse of the rule.

## Known gap

The current face is European. The audience is Indian exam candidates, and the
photo they are told to match should look like someone they recognise. The
generator used ignored its own age filter on non-default ethnicities and
returned children, so this is a placeholder rather than a settled choice.
Replacing it is the change below and nothing else.

## Replacing it

Drop a new file here and run:

    python scripts/generate_guidance_examples.py

The script refuses to run if the file is missing rather than falling back to a
fixture: a wrong "ideal" is worse than a missing one.

**Never put a real candidate's photograph here** (AGENTS.md).
