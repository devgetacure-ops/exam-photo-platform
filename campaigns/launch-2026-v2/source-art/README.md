# Source-art provenance

These three images were generated specifically for the ExamUploadKit launch
campaign. They contain no product interface, official examination form, real
candidate photograph or readable rule text. Anonymous portrait-like elements
are synthetic and intentionally unidentifiable.

- `why-problem.png`: pressure and friction at a late-night preparation desk.
- `how-system.png`: physical precision-system metaphor for exam-specific file
  preparation.
- `what-kit.png`: resolved portfolio tray containing distinct application-file
  forms.

The generated images never contain the logo or final campaign copy. The
authorised logo excerpts and exact wording are composited by
`scripts/render-campaign.mjs`, keeping brand artwork and claims deterministic.
