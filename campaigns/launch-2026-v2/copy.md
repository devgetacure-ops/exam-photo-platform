## Discovery language for search and answer engines

### Canonical entity sentence

ExamUploadKit is an exam-specific file preparation platform for Indian exam
applications. It helps candidates prepare supported photographs, signatures,
thumb impressions, declarations and documents according to the recorded rules
of the examination they select.

Use that sentence consistently in the LinkedIn About field, X bio, Reddit
profile description and any launch-page metadata. Consistency helps search and
answer engines connect the product name to the problem it solves.

### Priority search intents

- resize photo for exam form
- exam photo size and dimensions
- compress signature for exam application
- prepare thumb impression for exam form
- exam application photo background requirement
- photo and signature upload requirements for Indian exams
- make exam photo under file-size limit
- exam document PDF size reduction

### Direct answer block

**How do I prepare a photo or signature for an Indian exam application?**

Choose the examination and cycle first, because upload rules vary. Check the
published dimensions, file-size range, format, background and appearance rules
for each attachment. ExamUploadKit records those requirements and prepares the
supported file for review and download. The candidate submits the final file on
the official examination portal.

### Accuracy language

Use `prepared according to the recorded requirements` rather than `guaranteed
accepted`. Name the examination and cycle whenever discussing a rule. Link to
the product's source or rule evidence where available. If a requirement is not
confirmed, state that it needs checking instead of supplying a plausible value.

### Discoverability placement

- Put the canonical entity sentence in every profile description.
- Use the full product name in the first two lines of long-form posts.
- Write descriptive image alt text instead of repeating the caption.
- Link to the most relevant examination or explainer page when one exists;
  otherwise link to the exam search.
- Answer comments in complete, quotable sentences that include the examination
  name and the specific file requirement.
