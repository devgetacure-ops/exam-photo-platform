# ExamUploadKit product journey campaign

This package replaces the screenshot-led product overview with a guided application journey. The interface appears only where it proves a step; annotations, rule cards and process diagrams explain what happens around it.

## Story

1. Find the examination.
2. See what the form asks for.
3. Keep the files you need.
4. Let each file follow its own preparation path.
5. Inspect a protected result before paying.
6. Pay only after review.
7. Download, email or remind yourself.
8. Know the rules, limits and privacy boundary.

## Deliverables

- `exports/instagram-product-overview/` — eight 1080 x 1350 PNG slides.
- `exports/linkedin-product-overview/` — eight 1200 x 1500 PNG slides and a PDF document.
- `exports/reddit-product-overview/` — six 1080 x 1080 PNG cards.
- `exports/x-product-overview/` — four 1600 x 900 PNG cards.
- `exports/reviews/` — contact sheets for final visual inspection.

Run `node campaigns/launch-2026-v4/scripts/render-product-journey.mjs` from the repository root.
