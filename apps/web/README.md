# Public User Web Application

## Future Responsibility
This directory will contain the user-facing single-page web application. It will allow candidates to select an examination cycle, view basic requirements, upload their photo, view a compliance preview, and download the processed image.

## Expected Boundaries
- Communicates with the core Application API.
- Must not perform direct database queries or direct image processing.
- Handles responsive layouts to support mobile-first candidates.

## Dependencies
- React / Next.js (planned).
- Tailwind CSS / Vanilla CSS (details in architecture).
