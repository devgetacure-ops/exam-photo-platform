# Exam Rules Package

Contains the canonical language-neutral schema definitions for Indian Exam Photo compliance rules.

## Canonical Schema Location
The canonical JSON Schema is located at:
[exam-rule.schema.json](schema/exam-rule.schema.json)

All typed language implementations (including Python Pydantic models) must conform to this schema configuration.

## Package Boundaries
- Contains official JSON Schema declarations.
- Distributes language-neutral examples of valid and invalid rules configurations.
